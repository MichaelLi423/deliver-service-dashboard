# Vibe Coding 浏览器幻灯片

28 页、90 分钟，面向中文技术混合受众。课件是一个零依赖 HTML 文件，可离线演讲；页 8–11 使用依据已核验步骤和历史输出摘要重新排版的静态重构材料，不是原始界面截图，也不是现场 Agent 输出。项目段打开 OpenCode 已有历史会话讲解已有输出，不重新运行 Agent 或历史命令。

## 打开

直接用现代浏览器打开 [`index.html`](./index.html)，`file://` 下即可完整使用，无需安装依赖、启动服务或联网。

建议演讲前使用 1366×768 或更高分辨率打开，按 `F` 进入全屏，并跳到页 10、19、23、26 检查本机字体换行。演讲前关闭通知和其他敏感窗口。

## 操作

- 下一页：`ArrowRight`、`PageDown`、`Space` 或“下一页”按钮；
- 上一页：`ArrowLeft`、`PageUp` 或“上一页”按钮；
- 首尾页：`Home` / `End`；
- 全屏：`F` 进入或退出，`Escape` 退出；
- 触控设备：横向滑动；
- 深链：URL hash 使用 `#slide-10` 形式，刷新后保持当前页。

页面底部显示进度和当前/总页码。按钮支持键盘焦点；系统启用“减少动态效果”时会关闭转场动画。浏览器打印会按 16:9 逐页分页。

## 验证

演讲前在桌面与手机宽度检查首、中、末页及信息密集页，确认没有横向滚动或关键内容裁切。结构检查应确认：恰好 28 个 `section.slide`、ID 唯一、每页均有标题、控制按钮和键盘脚本存在。
