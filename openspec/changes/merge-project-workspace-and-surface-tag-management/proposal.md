## Why

当前工作台将项目详情与当前上下文分置在双列区域，提醒泳道不能独占主操作空间，详情固定高度还会裁切内容；同时全局标签库入口藏在“数据管理”二级菜单中。合并为单一项目工作区并直接提供标签管理入口，可让负责人按提醒、项目上下文和详情连续完成项目处理。

## What Changes

- 顶部主导航直接显示“标签管理”，仍打开现有全局项目分类标签库维护功能，不再仅通过“数据管理”二级菜单进入。
- 将项目提醒日期泳道改为独占整行，并在其下方按真实 DOM 顺序放置全宽的单一“项目工作区”及高密度项目队列。
- 项目工作区顶部以当前上下文摘要条呈现状态、分类标签、当前提醒、金额闭环、执行联系与既有动作；下方复用现有项目详情 tabs，二者共享同一选中项目和联动状态，不重复渲染组件或维护状态。
- 移除工作台双列布局及项目详情固定高度导致的内部裁切；保证页面级不横向溢出，必要宽内容仅在所属区域滚动，并保持 1440px、1190/1170px 与 1024px 桌面宽度可用。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `workbench-interface`: 调整工作台导航、提醒/项目工作区/队列的布局、当前上下文与项目详情的合并联动及桌面可用性要求。

## Impact

- 受影响：renderer 工作台入口、组件 DOM 结构与样式，以及对应 renderer 和 Playwright E2E 覆盖。
- 不修改后端、数据库、IPC 契约、外部 API 或依赖。
