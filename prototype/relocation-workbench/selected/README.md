# 搬迁服务工作台 · 选定方案高保真原型 v0.2

## 原型定位

客户已选择以 **A「任务指挥台」**为主，并保留 B 的「生命周期吞吐」与 C 的「当前上下文」。v0.2 在原有柔和主题、信息层级与主操作流上同步最新业务规则，不改变整体设计方向。

这是可交互评审原型，不是生产系统。所有提交只更新当前页面内存，刷新或关闭页面后会重置。

## 打开方式

直接双击 `relocation-workbench-selected.html`。文件完全自包含，可通过 `file://` 运行，不依赖服务器、外部资源或网络请求。

如需使用本地静态服务器，在仓库根目录执行：

```bash
python3 -m http.server 4173 --directory prototype/relocation-workbench/selected
```

然后访问 <http://localhost:4173/relocation-workbench-selected.html>。

## v0.2 评审范围

### 四步新建项目

1. **基本信息**：进单时间、区域、旧址与新址联系人、合同开始与截止日期，以及正式进单所需的项目、客户、ECC 与合同金额。
2. **搬迁范围**：旧址、新址、仪器名称、型号与 UPS。
3. **执行准备**：分别记录计划上门与计划运输时间、场地确认、实际装机完成时间、服务单号与参与工程师。填写服务单号时必须选定工程师，满足条件后项目与搬迁开单同次创建。
4. **确认方式**：检查摘要，并选择待进单、正式进单或未进单先执行。

合同日期、正式进单时间和服务单工程师均有就地校验；实际装机完成会记录执行事实，只有已正式进单项目才进入待验收，待进单和未进单先执行项目仍保持待进单，后续正式进单时再按已有事实跳转。未填写实际装机完成时间不会产生待办。

### 项目快速记录

快速记录严格提供十类动作：搬迁批次、搬迁仪器、上门活动、开单记录、物流费用、验收报告、掉票、Ship-to 申请、损坏/维修事项、补齐进单核心资料。

- 批次报价使用人民币原价与折后价；物流费用另表记录登记日期、预算价格、成交价格与物流费用。
- 物流费用三项金额均须大于 0；成交高于预算只提示，不阻塞保存，并动态展示成交与物流费用差异。
- 开单覆盖搬迁、认证、单寄备件、PM 四类，显示参与工程师，备注可后补；非空服务单号全局唯一。
- Ship-to 申请只记录客户、新址、状态与外部返回的 Account ID，不关联仪器，也不保存结构化快照；完成时 Account ID 必填且全局唯一。
- 损坏/维修事项一次损坏对应一条事项和一个备件；多个备件分别建立事项，支持 USD/RMB 与固定汇率提示。
- 搬迁仪器可手工标记“二维码是否申请”是或否，不存链接，也不生成待办。

### 独立模块

顶部提供两个不依附项目快速记录的模块入口：

- **二维码申请**：记录申请人、申请时间并多选九类固定类型，动态展示按去重类型计算的工作量；不关联仪器或项目。
- **序列号地址更新**：按仪器逐台记录客户、新址、序列号、Account ID 与更新时间，提供列表和组合筛选；保存更新事实不会修改不可变 Ship-to。

### 待办、状态与取消

标准待办只演示七类：缺进单核心资料、缺可后补字段、缺目的地址/Ship-to、缺工程师、缺运输公司、Ship-to 申请未完成、批次运输后缺物流费用记录。另保留自定义待办示例。

“缺目的地址/Ship-to”示例明确绑定已有实际装机事实的仪器。项目取消会提示不可恢复；存在任何掉票历史时禁止取消。金额输入有值必须大于 0，不允许以 0 完成金额闭环。

## 推荐评审路径

1. 点击生命周期阶段、项目行与待办，检查项目队列、当前上下文和详情的联动。
2. 完成四步向导；在服务单号存在时清空参与工程师，确认三个保存路径都会阻止保存并就地提示。
3. 分别打开搬迁批次与物流费用表单，检查人民币字段、正数校验、预算警告和差异预览。
4. 从快速记录检查十类项目动作；从顶部进入二维码申请和序列号地址更新独立模块并提交记录。
5. 在搬迁仪器表单手工切换二维码标记；在损坏/维修事项中切换币种和处理状态。
6. 对有、无掉票历史的项目尝试取消，检查禁止条件与不可恢复提示。
7. 在 1440px 与 1024px 宽度下检查主布局；宽表格应只在自身区域滚动，不产生页面级横向滚动。
8. 使用 Escape 或点击遮罩空白处关闭弹层，确认表单焦点、校验与 Toast 反馈。

## 视觉与运行边界

- 保持已选任务指挥台的柔和自然企业主题、紧凑生命周期、待办主操作流和常驻项目上下文。
- 中文正文与表格以 14–15px 为主，辅助文字原则上不低于 12px。
- 无外部字体、图片、CDN、网络请求、后端或持久化。
